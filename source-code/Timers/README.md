# Timer Utilities

**Book:** [Haskell Tutorial and Cookbook](https://leanpub.com/haskell-cookbook) by Mark Watson — [read free online](https://leanpub.com/haskell-cookbook/read)

**Book Chapter:** [Tutorial on Impure Haskell Programming](https://leanpub.com/read/haskell-cookbook/tutorial-on-impure-haskell-programming)

Demonstrates timing and timeout utilities in Haskell using `Data.Time.Clock.POSIX`, `System.TimeIt`, and `System.Timeout`. The example times a prime number sieve computation to show how to benchmark Haskell code and set execution time limits.

## Run

```bash
stack build --exec TimerTest
```
